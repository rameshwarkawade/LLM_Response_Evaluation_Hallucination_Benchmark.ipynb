## Results

The benchmark evaluates LLM responses at the claim level and identifies:
- Supported claims
- Unsupported claims
- Contradictory claims
- Hallucinated content

The system generates quantitative evaluation metrics and benchmark reports to compare response quality and factual grounding.

## Key Capabilities

- Claim-level hallucination detection
- Evidence-based fact checking
- Contradiction detection
- Threshold calibration
- Automated benchmark evaluation
- Response quality scoring
